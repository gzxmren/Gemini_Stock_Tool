# 股票助手 (Stock Analyzer & Screener PRO) 设计说明书

## 1. 项目目标 (Project Objective)
旨在为普通用户打造一款跨平台（中/美股）的桌面端股票分析与筛选工具。通过“极简、直观”的界面，将复杂的金融数据转化为易于理解的决策辅助信息。核心价值在于提供“历史估值水位”纵向分析，以及基于行业维度的横向对比。

## 2. 核心功能模块 (Core Functional Modules)

### 2.1 深度估值分析 (Advanced Valuation Analysis) - **核心优先级**
- **纵向对比 (Historical Percentile)**：展示当前 PE/PB 在过去 3-5 年历史区间的位置（分位点）。
- **水位计可视化**：直观展示历史最低、均值、最高及当前位置，辅助用户判断“贵贱”。
- **横向对比 (Peer Comparison)**：支持将当前个股与同行业其他主要公司的估值指标进行并列对比。
- **专业 DCF 绝对估值模型 (Professional DCF Model)**：
  - **自动数据抓取 (Auto-Fill)**：利用 `yfinance` 等接口抓取最新一期 (TTM) 的财务数据作为估值基准，包括：营收、利润率、有效所得税率、折旧摊销 (D&A)、资本开支 (CAPEX)、营运资本变动 (ΔWC)、有息负债、现金、少数股东权益及总股本。
  - **WACC 与市场参数**：自动获取或估算无风险利率 (Rf)、β 系数、市场风险溢价 (MRP) 以及债务成本，从而计算出加权平均资本成本 (WACC)。
  - **交互式预测表 (Cash Flow Projection)**：展示类似 Excel 的未来 5/10 年自由现金流 (FCFF) 推演表格。公式：`EBIT*(1-T) + D&A - CAPEX - ΔWC = FCFF`。
  - **估值瀑布桥 (Valuation Bridge)**：清晰展示从企业价值 (EV) 到股权价值，再到每股内在价值的计算过程：`股权价值 = EV(预测期现值 + 终值现值) - 净负债 - 少数股东权益`。
  - **估值结论与安全边际**：计算合理价值后，自动比对当前股价，输出明确结论（如：“极度低估 (安全边际 +30%)”、“合理估值区间”、“严重高估 (透支风险)”）。
- **分析师一致预期 (Analyst Consensus)**：
  - 汇总华尔街/国内券商分析师对该股票未来 1-2 年的目标价预测。
  - 图形化展示目标价的：最低值 (Low)、中位数值 (Median/Mean) 和 最高值 (High)。
  - 对比当前股价，提示华尔街预期上涨/下跌空间。

### 2.2 自选股与持仓追踪 (Portfolio & Watchlist)
- **自选列表**：用户可搜索并收藏感兴趣的中美股票。
- **持仓计算器**：支持输入买入价格和数量，实时计算单笔及总体的盈亏 (P&L)。
- **数据持久化**：使用本地 SQLite 数据库保存用户的自选和持仓数据，保障隐私且无需注册账号。

### 2.3 选股器 (Stock Screener)
- **基础筛选**：提供简单的条件过滤（如：PE < 15, PB < 1, 股息率 > 3%）。
- **发现列表**：根据预设策略（如“低估值成长”、“高股息蓝筹”）自动生成每日关注名单。

### 2.4 可视化财务报表与 K 线 (Financials & Charting)
- **趋势分析**：通过柱状图展示最近 5-8 个季度的营业收入和净利润。
- **K 线图表**：支持日/周K线，集成成交量和简单移动平均线 (MA5/MA20)。

### 2.5 新闻与公告聚合 (News Aggregation) - **Phase 2**
- **个股快讯**：实时拉取与当前个股相关的重大新闻和官方公告。

## 3. 技术架构与部署 (Architecture & Distribution)

- **桌面外壳**: Electron (跨平台窗口管理)。
- **前端 UI**: React + TailwindCSS + Lucide Icons。
- **图表引擎**: ECharts。
- **后端服务**: FastAPI (Python) - 负责数据抓取与计算。
- **本地数据库**: SQLite。
- **数据采集**: `yfinance` (美股), `httpx` (腾讯/新浪 A股接口), `AkShare` (宏观及行业数据)。
- **打包部署**: 使用 `PyInstaller` 将 Python 后端打包为可执行文件 (Sidecar)，配合 `electron-builder` 生成一键安装包，确保用户无需预装 Python 环境。

## 4. 数据流设计 (Data Flow)

1. **实时查询**: 前端请求 -> Python 后端 -> 抓取 API -> 整理成统一 JSON -> 前端渲染。
2. **本地存储**: 用户操作自选/持仓 -> 前端请求后端 -> 后端写入 SQLite -> 返回成功状态。

## 5. 错误处理与用户体验 (UX & Error Handling)

- **网络容错**: 针对第三方 API 增加 3 次自动重试机制和 5s 超时限制。
- **界面反馈**: 查询时显示加载动画；失败时显示具体的中文错误提示。
- **离线访问**: 离线状态下自动加载本地 SQLite 中的最后一次快照数据。
